# Mykola Nazarov — professional website

A self-contained English-language website for GitHub Pages. No installation, build step, third-party trackers, or API keys are required.

## Publish

Create the public repository `nikolay-baltics.github.io` in the `nikolay-baltics` GitHub account. Upload the contents of this folder to the repository root. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then save.

## Update

- `index.html`: biography, research, selected publications, experience, speaking and contact.
- `cv.html`: printable professional CV (the Print / Save as PDF button uses the browser’s print dialog).
- `styles.css`: responsive layout, colours and typography.
- `script.js`: mobile navigation and publication filters.
- `assets/`: supplied professional photographs.

Add publication entries as `<article class="publication" data-year="2026" data-topic="recovery">` elements. Supported topic values are `resilience`, `recovery`, and `security`. Add new years to the year selector when needed. The article text and links remain available without JavaScript.
